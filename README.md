## 🔍 Overview

FARISHTAA helps users describe symptoms via text or voice and sends them expert-level suggestions for the right medical specialty — while **avoiding medical diagnoses**.

---

## ✨ Features

- 🩺 Symptom input via text & speech  
- 🧠 Rule-based logic for categorization  
- 📊 Specialist recommendation engine  
- 🔄 Backend validation  
- 🔊 Speech-to-Text support
